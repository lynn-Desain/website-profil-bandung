# Profil Kota Bandung — Website Modern

Website profil Bandung versi modern, responsif, dan ringan.

## Struktur
- `index.html` — halaman utama
- `assets/style.css` — seluruh styling responsif
- `assets/script.js` — menu mobile dan efek header
- `assets/image/` — aset gambar yang diberikan

## Cara menjalankan
1. Ekstrak folder.
2. Buka `index.html` langsung di browser, atau gunakan Live Server di VS Code.
3. Untuk deployment, upload seluruh isi folder ke hosting.

## Fitur
- Header sticky dengan navigasi Sejarah, Geografis, Wisata
- Hero section modern
- Layout artikel sejarah dan geografis
- Kartu wisata Farm House Lembang dan Observatorium Bosscha
- Sidebar/profil Kota Bandung dengan lambang Bandung
- Footer dengan lambang Bandung dan teks Dicoding
- Responsive mobile/tablet/desktop
- SEO dasar: title, description, keywords, semantic HTML
- Menu mobile tanpa framework
